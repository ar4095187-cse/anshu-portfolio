ANSHU KUMAR - PERSONAL PORTFOLIO
=================================

FILES
- index.html: website content and structure
- style.css: design, colours, layout and responsive styling
- images/profile-placeholder.svg: temporary profile image
- images/favicon.svg: browser tab icon

HOW TO OPEN
1. Keep the folder structure unchanged.
2. Double-click index.html to open the website in a browser.
3. Keep an internet connection active for the embedded Google Map.

HOW TO ADD YOUR PHOTO
1. Copy your chosen photo into the images folder.
2. Rename it to profile.jpg.
3. Open index.html in a text editor.
4. Find: images/profile-placeholder.svg
5. Replace it with: images/profile.jpg
6. Save and refresh the browser.

BEFORE SUBMISSION
- Replace your-email@example.com with your real email address.
- Edit the interests so they describe your real hobbies.
- Add your school history, actual skills, projects and social profile links if you want.
- Check every link and make sure your photo appears.
- Keep index.html, style.css and the images folder together.

HOSTING
Upload index.html, style.css and the images folder to a GitHub repository.
Enable GitHub Pages in Settings > Pages, using the main branch and root folder.
